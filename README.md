# CampusConnect

## Project Description
CampusConnect is a student-focused website prototype designed to help college students discover, explore, and register for campus activities. The website brings academic, sports, and social events together in one place, making it easier for students to find activities that match their interests.

## Project Objectives
- Help students discover campus events.
- Organise events into academic, sports, and social categories.
- Allow users to search and filter available events.
- Display event details, including dates, locations, and descriptions.
- Allow users to register for and cancel event registrations.
- Provide a My Events section to view registered activities.
- Apply Human-Computer Interaction (HCI) principles to improve usability and user experience.

## Technologies Used
- **HTML5:** Structures the website content.
- **CSS3:** Controls the layout, colours, typography, and responsive design.
- **JavaScript:** Implements search, filtering, event details, registration, and cancellation.
- **Browser localStorage:** Stores registration information locally in the browser.

## Main Features
1. **Homepage:** Introduces CampusConnect and displays event images.
2. **Event Categories:** Organises activities into Academic, Sports, and Social sections.
3. **Search Function:** Helps users find events using keywords.
4. **Category Filter:** Allows users to filter events by category.
5. **Event Details:** Displays additional information about selected events.
6. **Event Registration:** Allows users to register for activities.
7. **My Events:** Displays events the user has registered for.
8. **Registration Management:** Allows users to cancel registrations and receive feedback messages.

## Project Folder Structure
CampusConnect/
- `index.html` — Main website page.
- `style.css` — Website styling and layout.
- `script.js` — Interactive functionality.
- `_images/` — Images used throughout the website.
- `README.md` — Project documentation.

## How to Run the Project
1. Download or extract the CampusConnect project folder.
2. Ensure that `index.html`, `style.css`, `script.js`, and the `_images` folder are in their correct locations.
3. Open the project folder.
4. Double-click `index.html` to open the website in a web browser.
5. Explore the event categories, search and filtering functions, event details, and registration features.

## Human-Computer Interaction
CampusConnect applies HCI principles to provide a clear and user-friendly interface. These include consistent navigation, readable text, visible interactive controls, feedback messages, and a structured layout. The website aims to make event discovery and registration simple and convenient for students.

## Data Storage
The prototype uses browser localStorage to retain event registration information in the same browser. It does not currently use a backend server or a shared database. Registration information is therefore local to the browser rather than shared between different users or devices.

## Limitations
- The website is a front-end prototype.
- Events and event details are sample content for demonstration.
- There is no user account or authentication system.
- Registrations are not submitted to a central database.
- Accessibility and usability require further testing with users and assistive technologies.

## Future Improvements
- Add user accounts and secure authentication.
- Connect the website to a database.
- Allow event organisers to create and manage events.
- Add event reminders and notifications.
- Introduce student comments or discussion features.
- Conduct accessibility and usability testing.

## Conclusion
CampusConnect demonstrates how an interactive website can help students discover campus activities and manage event registrations. The prototype provides a foundation for a more complete campus event management platform.
